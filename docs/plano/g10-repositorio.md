## Passos
1. `docker-compose.yml` (nome do projeto `ai-creator`): serviços `db` (postgres:16-alpine, usuário/banco `aicreator`, healthcheck), `server` (build ./server, envs do contrato, `DATABASE_URL` montada, volume `dados:/data`, healthcheck em `/api/saude` na 3333, depends db healthy), `client` (build ./client, porta `${WEB_PORT:-8080}:80`, depends server healthy), `trainer` (build ./trainer, volume `dados:/data`), `builder` (build ./builder, volumes `dados:/data` e `platformio:/root/.platformio`; bloco comentado mostrando `devices: ["/dev/ttyUSB0:/dev/ttyUSB0"]` para Linux), `ollama` (image `ollama/ollama:0.6.8`, `profiles: ["ollama"]`, volume `ollama:/root/.ollama`). Variáveis com padrão `${VAR:-...}`. Volumes `dados_db`, `dados`, `platformio`, `ollama`. `restart: unless-stopped`.
2. `.env.example` com todas as variáveis (comentadas em português), incluindo `ANTHROPIC_API_KEY=`, `OPENAI_API_KEY=`, `WEB_PORT=8080`.
3. `instalar.sh` / `instalar.ps1`: checa Docker, cria `.env` a partir do exemplo gerando `JWT_SECRET` e `INTERNO_TOKEN` aleatórios, pergunta (opcional) as chaves de LLM, `docker compose up -d --build` (com `--profile ollama` se o usuário quiser), espera saúde e imprime URL + login padrão.
4. `README.md` no estilo do REF: banner/título, selos (licença MIT, Docker, React, TypeScript, Express, Prisma, PostgreSQL, TensorFlow Lite, PlatformIO, Claude), descrição, **sumário**, recursos (agentes LLM; agentes TinyML; datasets/treino; firmware/compilação/gravação; VS Code; Claude Code/MCP; tema claro/escuro; PWA), placas suportadas (tabela), arquitetura (diagrama mermaid dos serviços), início rápido (instalar.sh/ps1 e manual), login padrão, configuração (.env), integrações (resumo + link docs), estrutura de pastas, desenvolvimento local (server `npm run dev`, client `npm run dev`, trainer/builder via compose), roadmap curto (link SUGESTOES), contribuição, segurança, licença. Espaço para capturas (`docs/imagens/` — use `<!-- TODO: captura -->` sem quebrar links).
5. `docs/API.md`: todas as rotas do CONTRATOS §3 em tabelas por módulo, com exemplos curl de login, criar agente, executar (SSE), compilar.
6. `docs/ARQUITETURA.md`: serviços, fluxo de treino (sequência mermaid server→trainer→callback), fluxo de build, volume `/data`, autenticação (JWT + tokens `aic_`), convenção de módulos (server e client).
7. `docs/TINYML.md` (formato do CSV, arquiteturas, quantização, como usar `model_data.h` com TFLite Micro — exemplo de código), `docs/FIRMWARE.md` (placas, offsets, Web Serial, gravação no servidor no Linux, VS Code), `docs/INTEGRACOES.md` (VS Code: instalar `.vsix`, comandos; Claude Code: `claude mcp add ...`, plugin via marketplace, `.mcp.json.exemplo`, comandos `/ai-compilar` etc.).
